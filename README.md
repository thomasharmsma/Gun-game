# Gun Game

Gun Game is een 2D-schietspel gemaakt met JavaScript en Phaser 3. Versla vijanden, ontwijk kogels en probeer zo lang mogelijk te overleven!

## Functies

- De speler kan bewegen en richten.
- Je kunt op vijanden schieten.
- Vijanden vallen de speler aan.
- Kogels en botsingen worden verwerkt.
- Pauzemenu met verschillende opties.
- Startscherm en game-over-scherm.

## Besturing

| Toets / Invoer | Actie |
|---|---|
| W, A, S, D | Bewegen |
| Muis | Richten |
| Linkermuisknop | Schieten |
| ESC | Pauzeren / hervatten |
| H | Hitboxes weergeven of verbergen |

## Hoe start je het spel?

1. Download of clone deze repository.
2. Open de projectmap.
3. Start een lokale webserver in de projectmap.
4. Open het lokale serveradres in je browser.

Het spel gebruikt Phaser 3 voor de weergave, fysica en gameplay.

## Gebruikte technologieën

- JavaScript
- HTML
- Phaser 3

## Projectstructuur

- `index.html` — De hoofdpagina van het spel.
- `phaser.js` — De Phaser-game-engine.
- `src/main.js` — De configuratie van het spel en de verschillende scenes.
- `src/scenes/` — De verschillende schermen van het spel, zoals het startscherm en het game-over-scherm.
- `src/gameObjects/` — De code voor de speler, vijanden en wapens.
- `assets/` — De afbeeldingen en andere spelbestanden.
